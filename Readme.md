## ***Dotfiles for a minimalist Debian setup.***

This will include a ==🟣install script== that you can run by cloning the repo, entering the directory and using:

`````
bash bootstrap.sh
`````


> [!info] Important
> Don't run this as root, dont sudo the script or anything
> just run it as normal user privileges
